Generate a key or import an existing nsec/hex private key. Keys are kept in memory only and are cleared when you close or reload this tab.

Anyone with your private key can impersonate you. Never share it. Nostr posts are public; a relay can see your IP address and activity.

03 / Peer connection

Connect directly

Not connected

Exchange an offer and answer out of band to open an encrypted WebRTC data channel. No signaling server is used.

A public STUN service helps browsers find each other; some networks still require TURN, which this demo does not provide. Sharing signaling can reveal network details. Only exchange it with someone you trust.
